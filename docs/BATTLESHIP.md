# 海战棋 Battleship

海战棋是独立的第七款游戏，采用经典双人 10×10 规则。支持设备本地 AI、同机双人、Android LAN 和浏览器 WebRTC；不需要账号或远程 AI 服务。

## 规则

双方各有一片独立海域，行坐标 A–J、列坐标 1–10。每人秘密放置五艘舰船：

| 舰船 | 长度 |
| --- | --- |
| 航母 | 5 格 |
| 战列舰 | 4 格 |
| 巡洋舰 | 3 格 |
| 潜艇 | 3 格 |
| 驱逐舰 | 2 格 |

舰船只能横向或纵向笔直放置，不能越界或重叠。不同舰船之间必须至少间隔一格，横向、纵向和斜角均不能紧贴。两人都确认完整舰队后开始开火，舰队随后锁定。

每回合选择敌方一个未攻击的位置，再按「确认开火」。无论命中与否，均轮到对方；不采用命中奖励连射或齐射规则。命中某艘舰船的全部格子即击沉，击沉对方全部五艘舰船获胜。认输结束当前对局，终局后公开双方舰队；再来一局清空布阵和开火记录，并轮换先手。

击沉后，舰船周围一圈自动标为空格，无法再选作目标。自动排除不增加开火记录，也不额外消耗回合；此前已开火的格子保留原标记。边缘和角落只标记海域内的格子。

## 布阵与对战

- 选择舰船，点击海域指定起点，切换「横向 / 纵向」预览，按对应的「放置…」按钮确认。越界、重叠或紧贴其他舰船时不能确认。
- 已放置的舰船可重新选择、移动、旋转或移除。「随机布阵」生成完整合法舰队，「清空舰队」从头布置。
- 确认舰队后等待对手准备。对战中敌方海域用于选取目标，我方海域显示自己舰队与对方攻击。
- 选择目标只产生预览，确认后才实际开火。命中、未命中、击沉和自动排除同时使用标记、文字和颜色区分，空心圆表示击沉周边已排除的空格，顶部可查看本局「开火记录」。
- 舰船采用俯视图，按类型绘制航母跑道与舰岛、战列舰炮塔、巡洋舰舰桥、潜艇围壳和驱逐舰主炮。击沉后保留受损船体轮廓。
- 手机竖屏上下排列海域，宽屏并排显示；界面支持系统大字体。同机交接和切出应用时隐藏私人海域，接过设备后才显示当前玩家的舰队。

## 模式与 AI

「单人对战」使用设备本地侦察 AI，只接收 AI 自己的舰队和公开开火结果。它根据未击沉舰船的可能位置搜索，命中后追击相邻方向，并随机选择同等候选；遵守舰船间隔规则，自动跳过击沉舰船周围已排除的空格。

AI 不读取对手布阵、随机种子或完整房主状态。应用进入后台时暂停未执行的 AI 回合，回到前台后恢复；退出或重新开始会取消旧回合。

「同机双人」依次秘密布阵，每次确认舰队或开火后遮挡海域并交接设备。双方只查看自己的舰队，公开开火记录可在交接期间查看。

## 联机与隐藏信息

Android 可创建带四位口令的 LAN 房间，Android 或浏览器加入。浏览器打开主机网页后可从首页快捷加入，只需输入口令；支持扫描和手动填写地址、端口。两人连接后由房主开始，再各自布阵。

浏览器 WebRTC 通过邀请与回应建立双人直连，支持国内、国际、自定义 STUN 及同网关闭 STUN。邀请有效期 30 分钟；网络范围与限制见 [WebRTC 说明](WEBRTC_MULTIPLAYER.md)。

`BattleshipRoomCoordinator` 保存权威状态，房主本机也通过自己的 `BattleshipReplica` 接收私有快照。联机使用独立的 `battleship` 消息类型，协议版本为 1、规则版本为 2，沿用可靠传输、消息分片和 LAN 协议版本 3。

规则版本 2 与允许舰船紧贴的旧版房间不兼容，双方需使用相同版本。周边排除由公开的击沉记录推导，不额外传输对手舰队。

每份快照只含接收者自己的舰队、公开开火记录、舰队准备状态与房间状态。对手舰队在终局前始终为空；击沉时仅公开被击沉舰船的信息。邀请不含布阵。客人不接收完整规则状态、另一份私有视图或随机种子。

请求携带座位独立递增的请求编号和当前局次。双方可同时修改自己的布阵；房主对开火等轮流操作检查当前序号、回合和目标，重复、旧局或非法请求不能推进对局。断线暂停操作，恢复凭据绑定原座位，不能占用仍在线的座位。网络再来一局需要双方确认。

房主作为权威可以检查双方舰队，熟人房间需要信任房主。退出房间后对局丢失，未持久化舰队或棋谱；不支持房主迁移、文件导入导出或中途悔棋。

## 验证

```sh
dart analyze lib test
flutter test test/battleship
flutter test
flutter build web --release --no-wasm-dry-run --base-href /easyplay/ \
  --target test/battleship/rtc_browser_smoke.dart --output build/battleship-smoke
node tools/test_battleship_web.cjs
python3 tools/package_lan_android.py --debug
```

规则测试覆盖原子布阵、边界、横纵与斜角间隔、随机舰队、击沉周边排除、重复和非法攻击、命中与击沉、17 格胜利、认输、轮换先手、不可变私有视图、恶意快照和完整对局。网络测试通过真实 WebSocket 完成对局，并逐份检查私有快照、认证、断线恢复、重放防御和同时操作。

浏览器检查生产界面中的布阵预览与确认、开火确认、击沉周边标记及禁选、同机隐私、AI 暂停恢复、横竖屏，以及两个独立浏览器上下文之间的真实 WebRTC 对局、首条握手丢包、重连、完整终局和再来一局。测试桥接仅存在于独立测试目标，不加入产品构建。
