# 斗地主

斗地主是独立的第六种游戏，采用固定的经典三人规则（rulesVersion=1）。

## 开始游戏

首页选择「斗地主」：

- **单人对战**：你与两名设备本地 AI。AI 不使用外部引擎或网络模型。
- **同机三人**：每次操作后遮挡手牌，把设备交给下一位；下一位确认后才显示自己的牌。
- **局域网**：与其他棋类一样，先选择「创建房间」或「加入房间」。Android 建房后自动生成四位口令，显示可分享的地址和端口；加入页分别填写地址、端口、口令，也可扫描可加入的斗地主房间。主机提供内置网页，首页「快捷加入」只需输入口令，连接后等待房主开始。
- **WebRTC**：浏览器房主分别为玩家 2 和玩家 3 创建邀请。每位客人粘贴自己的邀请并把回应交给房主，房主导入对应回应。房主与两名客人使用独立 DataChannel，客人之间无需连接。

三人房间必须全部准备后由房主开始。房主可把空座位设为 AI，支持两名真人加一名 AI；已被真人占用的座位不会被 AI 取代。单人、同机与网络对局均可结束后再来一局；网络再来一局需要所有真人确认。

手机窄屏的手牌分两行重叠排列；点击或横向拖动选择，选牌上抬，使用「清空」撤销选择。「提示」仅按自己的手牌与公开牌局推荐，选择后还需按「出牌」。

## 固定规则

一副 54 张牌，每人 17 张，3 张底牌在叫分结束前保密。按座位顺序叫 1、2、3 分或不叫，非零叫分必须高于当前最高分。叫 3 分立即成为地主；全部不叫则重新洗牌，保留房间身份并轮换首叫座位。

地主取得公开底牌，持有 20 张并先出。地主先出完则地主胜；任意农民先出完则两位农民共同获胜。领出时不能不要；连续两人不要后，上一位出牌者重新领出。

牌型包括单牌、对子、三张、三带一、三带二、顺子、连对、飞机及其单/对翅膀、四带二单、四带两对、炸弹和王炸。普通牌必须类型、张数与连续主体长度一致，比较主体最高点数；炸弹可压普通牌，王炸最大。

固定边界：

- 顺子至少 5 张，连对至少 3 对，飞机主体至少两组连续三张；连续主体不含 2 或大小王。
- 飞机单翅膀使用不同点数，不使用主体点数，不同时带两张王；对翅膀使用不同点数的对子，不使用主体点数。
- 四带二单可带一对，不能带双王；四带两对须为两个不同点数的对子。
- 叫分仅决定地主，无下注、倍率、积分或货币结算。

## 身份与私有信息

`CardRoomCoordinator` 独立于棋类双人 `RoomCoordinator`，继续使用 `MessageTransport`、WebSocket 和现有 WebRTC 可靠有序传输/分片。斗地主使用 `LanMessageType.card` 独立信封（game=doudizhu、protocolVersion=1、rulesVersion=1）；棋类协议与双方人数限制保持原样。

房主保存完整权威 `DouDizhuSession`，每次操作验证认证座位、阶段、回合、牌的所有权与唯一性、合法牌型及请求 seq。非法动作不推进 seq 或改变手牌。公共状态只含剩余张数、叫分、已公开底牌、已出牌和回合。网络发出的每份原子快照包含公共状态、收件人自己的手牌、准备/连接状态及再来一局确认。

客户端 `DouDizhuReplica` 没有完整 Session，不接收权威事件日志、牌堆或洗牌种子。AI 只接收其所属座位的 `DouDizhuPlayerView`。原生 AI 计算使用 isolate；Web 按有上限的候选批次让出事件循环，房主通过回合版本取消过期结果。

每个真人座位获得独立的 256 位恢复凭据，绑定房间。连接中断后保留座位并暂停操作；LAN 使用「重新连接」，RTC 由房主为原座位重新创建邀请，只重建该座位的连接。恢复后用自己的当前私有快照替换旧状态，不重放扣牌。仍在线的座位不能被另一条连接用凭据夺走。

房间存活与身份仅保留在内存；房主退出后无法恢复，不提供主机迁移，也不持久化牌谱。房主作为发牌权威可以检查全部牌，熟人房间须信任房主。洗牌使用 `Random.secure()`，不构成对恶意房主的密码学公平证明。无 TURN 时部分网络无法直连，可切换国内/国际/自定义 STUN 或同网关闭 STUN。

## 验证

```sh
dart analyze lib test
flutter test
flutter build web --no-wasm-dry-run
python3 tools/package_lan_android.py --debug
flutter build web --release --no-wasm-dry-run --base-href /easyplay/ \
  --target test/doudizhu/rtc_browser_smoke.dart --output build/doudizhu-smoke
node tools/test_doudizhu_web.cjs
```

`test/doudizhu/` 包含牌型/比较、穷举小手牌生成器性质测试、随机完整对局守恒、有限视图 AI、真实三人 WebSocket、按接收者检查序列化消息、恢复身份与重放拒绝、私有快照、混合 AI、再来一局、关闭时取消 AI，以及首页和窄屏/同机交接控件测试。

浏览器 smoke 使用三个独立浏览器上下文和两条真实 DataChannel，检查私有发牌、公开出牌、单客人重连时另一连接存活、完成一局与再来一局，以及两名真人加 AI 的完整对局。还通过实际大厅控件复制两份独立邀请、粘贴回应、开始对局、叫分并选牌出牌，检查手机横竖屏溢出。测试桥接仅位于独立测试 target，不加入产品 Web 构建。CI 保留原有棋类 RTC 和主题 smoke，并新增斗地主 smoke。
