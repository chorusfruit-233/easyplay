# 五子棋 AI 搜索与强度验证

五子棋的人机与双 AI 观战使用竞技连珠，共用本地 Dart 搜索，无模型下载。开局决策通过 `GomokuAi.decide` 完成摆子、交换、给点和选点，正常行棋沿用下述战术搜索。防守重构保留三档原有的节点数、普通搜索深度和思考时间预算，重点改善同一预算内的战术判断。

## 搜索与防守

- 每个节点都先检查己方成五、对手立即成五的落点及必应手，强制应对不受普通候选数量截断。活四和双冲四按不同的下一手获胜点判定；两点同时受威胁时直接识别无法一手防住的局面。
- 评估同时考虑连形、跳四、活三和四三组合。双方威胁都参与候选排序；根节点存在紧急威胁时先逐一检查候选的立即安全性，再将剩余预算用于较长变例。
- 普通深度耗尽后继续搜索连续冲四、必应手，以及阻止对手下一手形成活四或双冲四的防守。初级、中级、高级分别预留 2、6、8 层威胁延伸；结果中的 `depth` 仍表示完整完成的普通迭代层数，不包含威胁延伸。
- 每次搜索拥有独立的双 30 位 Zobrist 置换表，缓存局面的上下界与最佳着法，统一换算将杀距离；另缓存最多 4096 个局面的候选与威胁。邻域计数与棋形缓存只更新受落子影响的区域，悔棋恢复原缓存；连珠合法性仍由正式规则核心检查。
- 连珠黑方的禁手不能作为合法攻击或防御。搜索能识别挡错一端后，下一手必须落在禁手点的防守陷阱。标准规则的长连不会被误判为必须阻挡的胜点。
- 初级的随机性仅用于安静局面的已搜索候选，立即获胜、必须挡五或已知必败的应手不会被随机选择。截止时间、节点限制、应用切后台和取消请求继续有效，搜索不修改真实棋盘。
- 中、高级在最近一次完整搜索迭代的同分安静候选中随机选择，评分容差为0；初级保留1500分范围内候选及75%的变化概率。根节点窗口覆盖整个可选评分区间，避免将Alpha-Beta剪枝返回的边界值误当作同分实值。未完成迭代、强制防守和已证明胜负的走法不加入变化候选。
- 竞技开局从规则核心允许的黑1、白2、黑3落点中选择，可覆盖26种指定棋形，黑1仍固定在天元。交换仍按局面评分决定，给点和选点只在同分时变化。开局决策不依赖内存中的固定棋谱，载入前三子尚未摆完的存档后也能继续。

## 回归与对照

`test/gomoku/ai_defense_test.dart` 覆盖所有档位抢胜与挡五、活四防守、四三攻防、标准长连以及连珠禁手陷阱的八种旋转/镜像。`ai_test.dart` 保留搜索预算、取消、棋盘隔离和规则合法性检查。

`ai_variety_test.dart` 使用固定随机种子检查重开后的开局形状变化（归并旋转和镜像）、中高级同分走法变化、开局存档恢复与复现，以及不同随机种子下的唯一必防点。

旧版 v1.7.0（提交 `bc2b301`）被冻结在 `test/gomoku/fixtures/legacy_gomoku_ai.dart`，只用于测试。`ai_strength_test.dart` 让两个版本在相同的六组开局中交换执黑/执白，并遍历全部三种规则，共 36 局；双方均为中级，限制 1000 节点、普通深度 3，使用宽松的 5 秒截止时间减少 CI 机器速度对节点对比的影响。回归要求新版总胜场和执黑/执白各自胜场均过半；为控制测试耗时，每局最多 120 手，未完成对局仍计入总局数，不能计为获胜。防守重构时的基线回归为 **28 胜、7 负、1 局未完成**（执黑胜 16/18，执白胜 12/18）；独立工具允许走满 225 手时，该未完成对局最终和棋。

增加开局与同分走法变化后，本轮重跑上述36局回归仍为 **28胜、7负、1局未完成**，执黑和执白各自胜场过半的要求均通过。以下产品预算与AOT数值为此前防守重构的对照记录。

同样的开局与换先，在产品中级预算（6000 节点、深度 3、700 ms）下，Dart VM 工具对比为 **28 胜、8 负**。高级预算（20000 节点、深度 5、1600 ms）下，将双方编译为 AOT 后为 **24 胜、12 负**，执黑与执白均胜 12/18。每组对照内双方的运行方式和预算一致。这是固定开局对旧搜索的回归数据；不同规则可能走出相同棋谱，样本间有相关性，不能据此推算人类对局胜率或 Elo。

可复现工具会保存每局完整棋谱及总胜负、平均耗时、完成深度，未完成对局单独列出，不计为获胜：

```bash
flutter test test/gomoku/ai_defense_test.dart test/gomoku/ai_strength_test.dart
dart run tools/benchmark_gomoku_ai.dart --pairs 6 --nodes 1000 --depth 3 --milliseconds 5000
dart run tools/benchmark_gomoku_ai.dart --pairs 6 --nodes 6000 --depth 3 --milliseconds 700
dart compile exe tools/benchmark_gomoku_ai.dart --output /tmp/gomoku-ai-benchmark
/tmp/gomoku-ai-benchmark --pairs 6 --level advanced --nodes 20000 --depth 5 --milliseconds 1600
```

默认输出为 `/tmp/gomoku-ai-benchmark.json`，可通过 `--output` 指定路径；`--variant` 支持 `freestyle`、`standard`、`renju` 或 `all`。完整应用回归仍包括 `flutter test`、`dart analyze lib test`、Web 构建和带局域网网页资源的 Android 打包。

竞技开局及棋手身份的回归见 `test/gomoku/professional_test.dart` 和 `professional_page_test.dart`。新旧搜索对比工具保留自由、标准、旧连珠三种历史规则作为固定测试条件，以便复用v1.7.0基准；这些配置仅用于算法回归，不出现在新对局或联机入口。
